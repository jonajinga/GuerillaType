# Edge lines of all 530 pages of the same scan, for
# scripts/check-running-heads.mjs.
#
# stripRunningLines() reads only the first two and the last two non-empty
# lines of each page -- EDGE = 2 -- both when it counts what recurs and
# when it decides what to drop. This file is those lines and nothing
# else: for each of the 530 real pages, in order,
#
#     [...solid.slice(0, 2), ...solid.slice(-2)]
#
# verbatim. Carrying the whole 675 KB book would be the same experiment.
# The equivalence was not assumed: the set of lines the function removes
# from this file was compared against a run over the full unabridged 530
# pages and is identical, line for line, in order.
#
# The page COUNT is load-bearing. The threshold is a fraction of it --
# floor(530 * 0.25) = 132 -- so a shorter file would not reproduce the
# behaviour, and that is the whole point of this fixture: the most common
# spelling of the running head occurs 106 times, which is below 132.
#
# Provenance: a scanned PDF of Octave Mirbeau's "Le Journal d'une femme
# de chambre" (1900, public domain), 530 pages, ~675,000 characters. Every
# page below is the verbatim return value of joinTextItems() in
# src/assets/js/engine/import-parsers.js for that page, taken by driving
# the real pdf.js extraction once in a browser. The 20 MB PDF itself is
# NOT in this repository.
#
# Do not tidy these by hand. They are evidence. The mangled words ("Avex"
# for "Avec", "CHAMBtlE" for "CHAMBRE") are what the scanner produced,
# and stripRunningLines() is judged by what it does to them.
#
# Format: a line starting "### " opens a section. A line that is exactly
# "#PAGE" starts a new page. Any other line starting with "#" is a
# comment. "#" does not occur anywhere in the book's text, so no content
# line can begin with one. Empty pages are real and are kept.
